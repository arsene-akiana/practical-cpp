# practical-cpp

Exercises and projects in **C++** completed as part of my Software Engineering studies at **CFI-CIRAS** (Brazzaville, Congo).

This repository focuses on building strong algorithmic and systems thinking through C++ — one of the most rigorous languages in computer science.

---

## 📁 Repository Structure

```
practical-cpp/
│
├── basics/             # Variables, types, control flow
├── oop/                # Classes, inheritance, polymorphism
├── memory/             # Pointers, references, dynamic allocation
├── algorithms/         # Sorting, searching, recursion
├── projects/           # Mini-projects and practical exercises
└── ...                 # More to come
```

---

## 🧠 Concepts Covered

- **Syntax & data types** — variables, arrays, strings, operators
- **Control flow** — loops, conditionals, functions
- **Object-Oriented Programming** — classes, encapsulation, inheritance, polymorphism
- **Memory management** — pointers, references, stack vs heap
- **Algorithms & complexity** — sorting, searching, recursion, Big O
- *And more as the learning progresses...*

---

## 🎯 Why C++?

C++ builds the kind of rigorous, low-level thinking that makes you a stronger engineer in every other language. Mastering memory, performance, and object-oriented design in C++ is a foundation that transfers directly to Java, Python, and systems programming.
